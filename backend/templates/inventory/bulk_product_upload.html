CSV Format

Your CSV must include vendor_name and name. The sku column is optional — if left blank, the system auto-generates one from the category name. All other columns are optional (default to 0/false).

Column Required Description
vendor_nameYesVendor name (created if new)
nameYesProduct name
skuNoAuto-generated if left blank
category_nameNoCategory name (used for SKU generation)
cost_priceNoDefaults to 0
retail_priceNoDefaults to 0
discount_priceNoDefaults to 0
is_on_saleNo1/0, yes/no, true/false
is_serviceNoFlags 100% margin item
is_variable_weightNoFlags Tingi fractional item
stock_quantityNoDefaults to 0
min_stock_levelNoDefaults to 0
child_skuNoIngredient SKU for composites
child_qtyNoIngredient quantity
